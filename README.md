# Volca Sample

A CSS recreation of the Korg Volca Sample digital sample sequencer.

![Korg Volca Sample](images/screenshot.png)

## About

This project recreates the Korg Volca Sample using HTML and CSS. It's a purely visual replica of the hardware synthesizer's front panel, including knobs, buttons, step keys, and the LED display.

## Usage

Open `index.html` in a browser to view the Volca Sample.
